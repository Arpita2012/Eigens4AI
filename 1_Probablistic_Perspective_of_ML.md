# A Probabilistic Perspective of Machine Learning



## 1. Big Picture

Machine learning assumes that data is generated by an unknown probabilistic process. Instead of treating data as fixed, we model it as random variables drawn from a probability distribution.

We assume there exists a joint distribution:

- Inputs: $X$ (features)
- Outputs: $Y$ (labels or targets)

Both are generated together according to an unknown distribution:

$$
(X, Y) \sim P_{XY}
$$

The central goal of machine learning is to learn a function:

$$
f: X \rightarrow Y
$$

that captures the relationship between inputs and outputs based on observed samples.

---

## 2. Probability Space: The Foundation

All probabilistic modeling is built on a probability space:

$$
(\Omega, \mathcal{F}, P)
$$

This structure defines how randomness is formally described.

### 2.1 Sample Space ($\Omega$)

The sample space $\Omega$ represents all possible outcomes of the underlying random experiment.

In machine learning, this can be thought of as:
- All possible data-generating events
- All possible worlds that could produce datasets

For example:
- All possible images that could exist
- All possible user behaviors in a system
- All possible text sequences in language modeling

---


### 2.2 Sigma-Algebra ($\mathcal{F}$)

A sigma-algebra is the mathematical object that defines which subsets of the sample space can be treated as valid events.

Formally, a collection $\mathcal{F} \subseteq 2^\Omega$ is called a sigma-algebra if:

$$
\mathcal{F} \subseteq 2^\Omega
$$

and it satisfies the following properties:

#### 1. Contains the full sample space
$$
\Omega \in \mathcal{F}
$$

#### 2. Closed under complements
If an event $A$ is in $\mathcal{F}$, then its complement is also in $\mathcal{F}$:

$$
A \in \mathcal{F} \Rightarrow A^c \in \mathcal{F}
$$

#### 3. Closed under countable unions
If we have a countable collection of events $A_1, A_2, A_3, \dots \in \mathcal{F}$, then their union is also in $\mathcal{F}$:

$$
A_i \in \mathcal{F} \ \forall i \Rightarrow \bigcup_{i=1}^{\infty} A_i \in \mathcal{F}
$$

---

### Intuition

The sigma-algebra $\mathcal{F}$ defines the set of all events for which probability is well-defined.

It restricts the power set $2^\Omega$ to only those subsets that behave consistently under:
- negation (complement)
- combination (countable unions)
---

## 3. Random Variables

A random variable is a function that maps outcomes from the sample space to a numerical representation:

$$
X: \Omega \rightarrow \mathcal{X}
$$

Here:
- $\Omega$ is the space of underlying randomness
- $\mathcal{X}$ is the feature or value space

In machine learning:
- The sample space represents how data is generated
- The random variable transforms outcomes into observed data

Thus, a dataset is viewed as samples of random variables rather than fixed points.

---

## 4. Measurability and Validity of Random Variables

Not every function from $\Omega$ to $\mathbb{R}$ is valid in probability theory. To ensure consistency, random variables must be measurable.

This means that for any meaningful subset of outputs, we can trace it back to a valid event in the sample space.

Formally, for any set $B$ in the output space:

$$
X^{-1}(B) \in \mathcal{F}
$$

This ensures that probabilities over outputs are well-defined through the underlying probability space.

---
## 5. Borel Sigma-Algebra

When working with real-valued outputs (which is standard in machine learning), we need a sigma-algebra on $\mathbb{R}$.

This is given by the Borel sigma-algebra:

$$
\mathcal{B}(\mathbb{R}) = \sigma(\mathcal{O})
$$

where $\mathcal{O}$ is the collection of all open sets in $\mathbb{R}$.

---

### What does $\sigma(\mathcal{O})$ mean?

The notation $\sigma(\cdot)$ means:

> “the smallest sigma-algebra generated by a collection of sets”

So:

$$
\mathcal{B}(\mathbb{R}) = \text{smallest sigma-algebra containing all open sets}
$$

---

### Construction idea

We start from simple sets:

- Open intervals:
  $$
  (a, b)
  $$

Then we repeatedly apply:
- complements
- countable unions
- countable intersections (derived from complements + unions)

This generates a very rich family of sets.

---

### What is included in $\mathcal{B}(\mathbb{R})$?

The Borel sigma-algebra contains:

- Open intervals: $(a,b)$
- Closed intervals: $[a,b]$
- Half-open intervals: $(a,b], [a,b)$
- Countable unions of intervals
- Countable intersections of such sets
- Many more “constructed” sets

---

### Why it matters in ML

The Borel sigma-algebra defines which subsets of $\mathbb{R}$ are measurable.

So when we define a random variable:

$$
X: \Omega \rightarrow \mathbb{R}
$$

we require:

$$
X^{-1}(B) \in \mathcal{F}, \quad \forall B \in \mathcal{B}(\mathbb{R})
$$

This ensures that probabilities like:

- $P(X \leq t)$
- $P(a \leq X \leq b)$

are all mathematically well-defined.

## Notation summary

- $\Omega$: source of randomness (data-generating process)
- $\mathcal{F}$: valid events (sigma-algebra)
- $P$: probability measure over events
- $X$: random variable mapping outcomes to data space
- $\mathcal{B}(\mathbb{R})$: structure defining measurable real-valued sets
